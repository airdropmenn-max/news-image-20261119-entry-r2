## Run it

```sh
python3 compose.py && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`compose.py` draws `entry.png` (1024x1024, deterministic, no network); `main.ts` copies it to the output directory and verifies the copy with SHA-256.
